# User Department Area

This area represents the department-specific review and interview workflow.

## Responsibilities

- department vacancy requests
- access to assigned candidates only
- user interview workflow
- department-specific review results

## Notes

- User Department access is limited and controlled by HR.
- Candidate visibility must follow assigned/recommended department access.
- This area must stay logically separated from HR administration.
- Do not bypass permission checks by hiding menu items alone.
