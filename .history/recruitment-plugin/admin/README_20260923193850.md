# Admin HR Area

This area contains the internal recruitment management experience.

## Responsibilities

- dashboard
- applicant management
- vacancy management
- recruitment workflow
- psychotest administration
- interview operations
- email recruitment
- configuration and account controls

## Notes

- This area remains the central source of HR coordination.
- Role-based access must remain enforced.
- User Department access must not be merged into HR logic.
- Preserve the current application functionality while improving maintainability.
