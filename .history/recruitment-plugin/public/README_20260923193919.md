# Public Site

This area contains the applicant-facing experience for the recruitment plugin.

It is intentionally separated from HR and User Department functionality.

## Responsibilities

- vacancy listings
- job details
- application form
- application tracking
- confirmation screens
- public recruitment workflow
- public navigation and presentation components

## Notes

- Keep candidate-facing logic distinct from internal HR logic.
- Do not expose HR-only data or private recruitment decisions in this area.
- Preserve the existing UI and behavior unless a request explicitly asks for a redesign.
