# Shared Layer

This directory is reserved for architecture-level reuse that genuinely spans multiple areas.

## Intended usage

- shared UI elements
- reusable data helpers
- shared validation and formatting utilities
- cross-area presentation components
- common logic that is not private to one role

## Notes

- Do not abstract or duplicate functionality unnecessarily.
- Prefer reusing existing working components before creating new ones.
- Keep this layer minimal and practical.
